# 0001: Todo CRUD 要件定義 (サンプル)

- ステータス: Approved
- 起票: 2026-11-23

> ボイラープレート同梱のサンプル。新機能はこのフォルダをコピーせず `/requirements` で作成する。

## 1. 背景・目的
ボイラープレートの各層 (UI / API / DB / テスト / 負荷試験) が一通り動くことを示す最小機能。

## 2. スコープ
- 対象: Todo の作成・一覧・完了切替・削除
- 対象外: 認証、マルチユーザー、並び替え

## 3. ユーザーストーリー
- 利用者として、やることを忘れないために、Todo を登録・完了・削除したい。

## 4. 機能要件 / 受入条件
| ID | 受入条件 | 優先度 |
|---|---|---|
| AC-1 | Given 画面を開いた When タイトルを入力して追加 Then 一覧の先頭に未完了で表示される | Must |
| AC-2 | Given タイトルが空白のみ When 追加 API を呼ぶ Then 400 VALIDATION_ERROR | Must |
| AC-3 | Given タイトルが 256 文字 When 追加 Then 400 (255 文字は成功) | Must |
| AC-4 | Given Todo が存在 When チェックを切替 Then 完了状態が保存され、再読込後も保持 | Must |
| AC-5 | Given Todo が存在 When 削除 Then 一覧から消え、取得 API は 404 | Must |
| AC-6 | 一覧は新しい順、limit は 1〜100 (既定 50)。`nextCursor` で次ページを取得でき、最終ページでは null | Should |

## 5. 非機能要件
| 区分 | 要件 |
|---|---|
| 性能 | 50 VU で p95 < 200ms, エラー率 < 1% |
